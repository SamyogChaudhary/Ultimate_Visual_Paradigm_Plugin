PlantUML ERD Importer - Visual Paradigm plugin (works in Community Edition)
==========================================================================

What it does
  Turns crow's foot ER diagrams written in PlantUML into real Visual Paradigm
  ER diagrams: tables, columns (PK, FK, data type, NOT NULL, unique),
  crow's foot relationships, and the diagram itself.

Install (once)
  1. In Visual Paradigm: Help > Install Plugin.
  2. Choose "Install from a zip of plugin" and pick PlantUML_ERD_Importer_plugin.zip.
     (Or unzip it and use "Install from a folder of plugin" with the plantuml.erd.importer folder.)
  3. Restart Visual Paradigm.
  It works alongside the OEO ERD Builder plugin; you can keep both.

Use
  Open your project, then in the Plugins tab click:
  - Import ERD File: pick one or more .puml files (you can select several at once).
  - Paste ERD Code: paste the code from @startuml to @enduml and click OK.
  Each @startuml ... @enduml block becomes one ER diagram, named after its title.
  The first new diagram opens; all of them are in the Diagram Navigator under
  Entity Relationship Diagram.

Importing again
  Tables already in the project (same name) are reused, not duplicated: their columns
  are kept and only missing columns are added. Relationships already there are reused.
  A diagram whose name is taken gets (2), (3) and so on. For a clean copy, import
  into a new project.

What the PlantUML can contain
  entity "TABLE" as T { ... }   or   entity TABLE { ... }   (class and table blocks work too)
    * name : TYPE <<PK>>      * means NOT NULL. Tags: PK, FK, UQ (or PRIMARY KEY, NOT NULL,
                              UNIQUE written after the type). Types like INT, VARCHAR(50), DECIMAL(10,2).
    --                        columns above this line are the key when nothing is tagged PK
  Crow's foot ends:  ||  exactly one    |o  zero or one    }|  one or many    }o  zero or many
    PARENT ||--o{ CHILD : label        PARENT |o--o{ CHILD        A ||--o| B
    A }o--o{ B   (many-to-many: a link table A_B is added for you)
  Optional hints, written as PlantUML comments (PlantUML itself ignores them):
    ' vp-fk column            on the line under a relationship: the child column holding the FK
    ' vp-pos TABLE x y w h    where to put a table; without these, Visual Paradigm lays it out

If something goes wrong
  A message shows what it was doing and why. Take a screenshot of it.
  A copy is saved as plantuml-erd-importer.log in the plugin folder (or your home folder).
